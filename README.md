# ✈️ TripPilot 2.0

An AI-powered full-stack travel management platform built with the MERN Stack that helps users plan smarter trips through intelligent itinerary generation, destination recommendations, budget tracking, and collaborative travel planning.

---

## 🌟 Features

- 🤖 AI-powered personalized travel itinerary generation
- 🌍 Smart destination recommendations
- 🗺️ Interactive trip planning and scheduling
- 💰 Budget planning and expense tracking
- 👥 Group trip collaboration
- 🔐 Secure JWT Authentication
- 📱 Fully responsive modern UI
- ☁️ Cloud-based MongoDB database
- 📊 Personalized travel dashboard
- ⚡ Fast and scalable REST APIs

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/kiranmedida/TripPilot.git
```

```bash
cd TripPilot
```

---

## Install Dependencies

### Frontend

```bash
cd client
npm install
```

### Backend

```bash
cd ../server
npm install
```

---

## Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000

MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

GROQ_API_KEY=your_groq_api_key
```

---

## Run the Project

### Start Backend

```bash
cd server
npm run dev
```

### Start Frontend

```bash
cd client
npm run dev
```

## Why TripPilot?

TripPilot simplifies travel planning by combining AI with modern web technologies. Instead of manually searching multiple platforms, users can generate complete travel plans, manage expenses, organize schedules, and collaborate with companions from a single application.
